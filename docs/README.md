## Purpose

This directory contains documentation that explains APES to a new reader: how to get started, what the lifecycle looks like, how stage gates work, how maturity is assessed, the shared vocabulary, and common questions.

- [`maturity-model.md`](maturity-model.md) — Levels of APES adoption.

Most reader-facing lifecycle documents remain placeholders in v0.1. `repository-evolution-plan.md` is an active Draft produced by Foundation 0.1, refined by Foundation 0.1.1, extended through the Foundation 0.2 reference architecture and Foundation 0.3 / F1 contract prototype, and updated for the independent F2 validator implementation.
