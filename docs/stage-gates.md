## What is a Stage Gate

A stage gate is the set of artifacts, evidence, and decisions required before moving from one stage to the next. Gates make it hard to skip validation and easy to audit later.

## Gate Outputs (Placeholder)

Concrete gate criteria will be added as each standard module is developed. Until then, the working assumption is:

- Each stage produces at least one document under the matching [`../standards/`](../standards/README.md) subdirectory.
- Each gate requires evidence with a source and access date.
- Each gate records decisions in [`../governance/decisions/`](../governance/decisions/README.md) where appropriate.

## Gate Discipline

- No stage gate is waived silently. If a gate cannot be met, record why and what compensating evidence exists.
- "We will add it later" is not evidence. Cite what you observed now.
