## Purpose

RFCs are the standard-level change proposal mechanism. An RFC moves through Proposed → Accepted or Rejected. Accepted RFCs may result in updates to one or more modules under [`../../standards/`](../../standards/README.md).

## Format

Each RFC will include:

- Summary
- Motivation
- Detailed proposal
- Impact on existing modules
- Backward compatibility
- Validation plan
- Open questions
