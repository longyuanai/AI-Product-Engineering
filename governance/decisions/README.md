## Purpose

Some decisions are real but do not warrant full ADR ceremony. This directory captures those choices so they remain auditable.

## When to Use

Use a decision note when:

- The decision is reversible without long-term cost.
- The decision affects at most one stage or one sprint.
- A brief context + decision + rationale paragraph is enough.

Escalate to an ADR if any of:

- Two or more stages are affected.
- The decision is hard to reverse.
- It changes a scope, naming, or process rule.
