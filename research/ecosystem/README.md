## Purpose

Notes in this directory describe parts of the AI tooling ecosystem — code agents, coding assistants, model providers, agent frameworks — at a level relevant to APES adoption decisions.

## Scope

In scope (planned):

- Vendor-neutral descriptions of categories of tools.
- Compatibility observations (e.g., does tool X work with APES's repository convention?).
- Notes on ecosystem changes that could affect APES guidance.

Out of scope:

- Rankings or "best tool" comparisons.
- Unverified adoption or market-share claims.
