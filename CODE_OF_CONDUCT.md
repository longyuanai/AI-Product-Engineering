## Status

A formal code of conduct will be adopted in a later sprint. The likely choice is the [Contributor Covenant](https://www.contributor-covenant.org/), but no version has been finalized.

Until then, participants are expected to:

- Be respectful in issues, pull requests, discussions, and reviews.
- Disagree with ideas, not with people.
- Avoid harassment of any kind.
- Report unacceptable behavior to the maintainers.

A full text of the adopted code of conduct will replace this file once selected.
