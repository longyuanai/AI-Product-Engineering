## Purpose

This module will describe how an AI product repository should be organized when it claims to follow APES. It will cover directory structure, naming conventions, the relationship between code, research, and decision records, and the minimum viable repository layout for an AI-assisted product team.

## Scope

In scope for this module (planned):

- A reference layout for an APES-compliant product repository.
- Required top-level directories vs. optional ones.
- Rules for naming modules, templates, and decision records.
- Linkage between this repository and any downstream APES-compliant project.

Out of scope:

- Implementing CLIs, MCP servers, or editor extensions.
- Vendor- or tool-specific configuration.
