## Principles

This roadmap is direction, not a contract. It will be revised as we learn from real projects and from community feedback. Each milestone requires evidence — at minimum one real case study showing the prior version in use.

## v0.1 — Foundation

- Repository structure and core documents.
- Research notes on ecosystem, competitors, and papers.
- Draft skeletons for each lifecycle-stage standard (no full content yet).
- One real-case study (design and data collection, not necessarily a finished product).

## v0.2 — Templates and Tooling Guidance

- Document templates for each lifecycle stage.
- Quality and stage-gate checklists.
- Worked examples for Claude Code, Codex, and similar AI coding tools following APES.
- Expanded glossary and FAQ.

## v0.5 — Real-World Validation

- At least three real cases, each touching multiple modules of APES.
- Automated repository checks (Markdown lint, link checks, structural validation).
- Community review of each module before promoting to Draft status.

## v1.0 — Stable Standard

- Each module has been used in at least one real project end-to-end.
- Stage gates are validated empirically, not just by committee.
- A migration / compatibility policy exists for prior drafts.
- Public announcement of stable release.

## Disclaimer

No date or feature is promised. This roadmap is updated as learnings accumulate.
